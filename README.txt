仮面ライダーCROWN 官网原型 v0.2

【Windows 本地预览】
双击 start-site.bat，浏览器会打开 http://localhost:4321
关闭黑色命令窗口即可停止本地网站。

【Mac 本地预览】
双击/运行 start-site.command。

【最常改的文件】
data/site-data.js    所有新闻、形态、人物、怪人、道具、剧情文字
assets/images/       图片素材
assets/css/site.css  全站视觉系统（一般无需每周修改）
