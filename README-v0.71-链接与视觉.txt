《假面骑士 Crown》官网 v0.71
=============================

本次只改代码和少量数据，不需要重新替换你的美术素材。

1. 关系链接不再显示 Logo / 分类 / 完整卡片
------------------------------------------
人物、武器、梦幻体等详情页里的关联关系，现在显示为简洁的下划线文字链接。
例如人物页：
    假面骑士 Crown ↗
点击后仍然直接进入 Crown 基础形态。

2. 骑士反向链接文案可自定义
----------------------------
在对应形态中增加：
    linkLabel:'假面骑士 Crown',

例如：
{
  id:'base',
  name:'CROWN',
  cn:'基础形态',
  linkLabel:'假面骑士 Crown',
  ...
}

人物页、武器页等自动反查骑士时，会优先显示 linkLabel。
不写则自动使用骑士名称。

3. 视觉调整
-----------
- 关联信息去卡片化
- 详情块改为不对称圆角 / 轻切角
- Hero 增加错位色条和立体层级
- 标题增加斜切栏目签
- 减少硬黑框和“后台管理系统”感
- 保留棋盘、徽记、蓝/红/金栏目主题

4. 你的图片不用重新覆盖
-----------------------
这版没有要求新的必备美术素材。
原有 assets/images 继续使用即可。
