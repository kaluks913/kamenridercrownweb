《假面骑士 Crown》官网 v0.3 —— 内容修改指南

你以后绝大多数时候只需要编辑：
  data/site-data.js

一、给骑士形态增加 / 删除“参数”
--------------------------------
找到对应形态的 stats，例如：

stats:[
  { label:'身高', value:'195.0 cm' },
  { label:'体重', value:'92.0 kg' },
]

增加：
  { label:'潜水时间', value:'30 min' },

删除：
  直接删掉整行即可。

参数数量没有上限，也不要求所有形态一样。


二、给设定图编号增加 / 删除部件说明
--------------------------------
找到 components：

components:[
  { no:'01', name:'圣蛇之眼', text:'这里写功能。' },
  { no:'02', name:'王权护肩', text:'这里写功能。' },
]

继续增加 03、04、11、12 都可以；编号不必连续。
删除整行即可消失。


三、主站道具 ≠ 伪玩具商品
--------------------------------
items = 剧中道具资料。
toys  = 现实世界“伪商品 / 套装”。

例如：
- 皇冠驱动器：一个剧中道具
- 国王捷能充芯：另一个剧中道具
- DX 皇冠驱动器：一个伪商品套装，同时包含上面两个剧中道具

因此它们不会强制一一对应。


四、让某个剧中道具【不要】出现玩具页按钮
--------------------------------
在 items 中写：

relatedToys:[]

或者整个 relatedToys 字段都删掉。

网页就不会生成“查看玩具”按钮。

例如国王捷能充芯目前就是：
relatedToys:[]

它仍然会正常出现在主站“捷能充芯”分类里，
但不会拥有一个假的“国王充芯单卖商品页”。


五、让某个剧中道具指向一个套装玩具页
--------------------------------
假设 toys 中有：

{
  id:'crown-driver-set',
  name:'DX 皇冠驱动器',
  ...
}

那么主站的皇冠驱动器可以写：

relatedToys:['crown-driver-set']

就会出现按钮。

如果一个剧中道具被收录进两个商品：
relatedToys:['set-a','set-b']
也可以。


六、新增一个“套装商品”
--------------------------------
在 toys 数组里复制一个对象：

{
  id:'crown-driver-set',
  name:'DX 皇冠驱动器',
  en:'DX CROWN DRIVER',
  category:'变身腰带套装',
  package:'toys/crown-driver-package.jpg',
  intro:'皇冠驱动器与国王捷能充芯组成的变身腰带套装。',
  includedItems:['driver','king-core'],
  manuals:[
    'manuals/crown-driver/01.jpg',
    'manuals/crown-driver/02.jpg',
    'manuals/crown-driver/03.jpg'
  ]
}

includedItems：盒内有哪些“剧中道具”。
manuals：说明书图片，想几页就几页。


七、完全没有伪玩具商品的道具怎么办？
--------------------------------
什么都不用做。
只保留在 items 里即可。
它会有完整的主站设定资料，但副站不会出现它。

这就是 v0.3 最重要的改动。
